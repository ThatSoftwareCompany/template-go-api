# Release v0.2.7

breaking: false

## Summary

Corrected publication of the template lifecycle hotfix for derived repositories.

## Fixed

- Publish the merged module-path normalization and legacy bridge fixes as a release target.
- Make lifecycle fixtures independent of `rg` and global Git identity configuration.
- Preserve custom Go module paths and application-owned routes during update validation.

## Incompatible changes

None.

## Migration

The immutable `v0.2.6` tag points to the previous foundation commit. Close any generated update pull request targeting `v0.2.6` and rerun the update workflow after `v0.2.7` is published. Repositories based on `v0.2.4` or newer can update directly to `v0.2.7`; older repositories should follow the documented `v0.2.3 -> v0.2.4` bridge first.
